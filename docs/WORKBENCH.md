# 入口、状态与恢复

浏览器工作台是已有 Python 科学服务的 loopback 适配器，没有另一份候选或 PubChem 算法。Tk 通过 `start_analysis` 缓存适配器调用 `analyze`；HTTP 后台直接调用同一 `analyze/validate_input`，并复用 `start_search` 及缓存完整性服务。

## 浏览器

`python -m workbench.server` → `http://127.0.0.1:8866`。HTML/CSS/JS 为本地静态资源，不加载 CDN、在线字体或遥测。固定 loopback；Host、Origin 与每个服务实例 token 验证阻止其它网站跨源发起计算/缓存写入。每类仅有一个进行中任务、最大两条后台线程；完成任务只留少量本机内存记录。不是公开网络服务。

| 状态 | 行为 |
| --- | --- |
| 当前结果 | 可选中、加入检索或导出；保存完整输入快照 |
| 参数变化 | 立即标记陈旧、阻止导出和发送；不会静默改成新参数结果 |
| 任务中 | 同类按钮锁定；输入可以修改，但旧快照响应不会回填 |
| 取消 | 引擎协作停止；完成→取消→首次 poll 的竞态也抑制成功回填 |
| 超限/非法/网络失败 | 保留此前数据和失败原因；可修正后重试 |
| 部分 PubChem 响应 | 明确展示缺口与排序限制，保留重试按钮和原始缓存 |

取消联网任务不强杀正在等待 HTTP 响应的线程；在超时前可能继续完成网络访问和可复用缓存写入，界面抑制回填并等待后台释放后再允许同类查询。枚举取消在 DFS 检查点真实停止。服务退出时请求所有任务取消；现有网络请求仍受项目超时/重试策略约束。

标准视口固定常见输入、行动按钮、结果与选中详情；大量结果分页并在表格内垂直/水平滚动。输入高级元素/算法说明在参数面板局部展开和滚动。窄窗口使用页面滚动，保留动作和横向可滚动表格。

JSON 打开在浏览器本机读取，不上传文件给服务。先验证完整文件再替换输入/结果；打开取消、格式损坏、未知元素或非有限质量均保留当前数据。v2 缺 H 恢复为 0；没有引擎版本的旧文件可按原 Tk 隐含 H 不限恢复，但保留原输入文件与历史提示。打开不是独立科学重算验收。

参数草稿仅存于当前浏览器 `mass-finding-draft-v2` localStorage。结果和 PubChem 队列不自动保存；设置内可清草稿，重载只恢复参数。JSON/CSV 下载不舍入原始质量，显示设置仅改变表格小数位。

## 保留的 Tk

`python run.py` 保留生成、检索、评分统计、bus、多条件筛选与 RDKit 结构详情。默认生成页、紧凑控件/导航、窗口约束以及可拖动和可滚动区域改善小屏使用。后台结果以 Future/线程安全队列交回 Tk 主线程；取消分析协作停止，不提前解锁或接受陈旧结果。导航期间运行状态仍保持关闭保护。

原生 JSON 导入不再切换全局 cwd；先校验全部候选、输入与加合关系，再恢复 H/DBE 和其它参数。分析/检索中禁止破坏性缓存动作，失败不擦除此前结果。评分统计明确启发分含义；非法阈值、取消保存与导出失败均保持已有结果，CSV 使用原子写入并保留统计阈值。

真实 Chrome 点击、像素、下载和滚动验收与 Tk 内部合同/动态测试分别记录。网页截图不用于证明 Tk 原生布局、鼠标或 Windows 安装体验。两个入口的验收边界见 `VALIDATION.md`。
